# ElasTech | Spring Boot

Repositório dedicado aos estudos e práticas de desenvolvimento backend com Java e Spring Boot, realizados durante o bootcamp ElasTech.

## Conteúdos

- Desenvolvimento de APIs REST com Spring Boot
- Controllers e mapeamento de rotas HTTP
- Requisições GET, POST, PUT e DELETE
- Parâmetros de rota (`@PathVariable`)
- Parâmetros de consulta (`@RequestParam`)
- Modelagem de classes e retorno de objetos JSON

*Os conteúdos serão atualizados conforme o avanço das aulas e atividades.*

## Tecnologias

- Java 21
- Spring Boot
- Maven
- IntelliJ IDEA
- Git e GitHub
